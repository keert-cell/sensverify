# CyberShield AI 🛡️

**Fake News & Scam Detection System** — Universal Multi-User Protection

## 🌐 Live App
[Click to Open CyberShield AI](https://cybershield-ai.streamlit.app)

## Features
- ✅ Universal Login — Any user, any phone number
- 🔴 Real-time scam/fake news detection
- 📲 Live SMS/Email auto-scan simulation
- 👥 Multi-user protection dashboard
- 🤖 ML-powered (TF-IDF + Logistic Regression)

## Tech Stack
- Python, Streamlit, Scikit-Learn, NLTK, Pandas

## Run Locally
```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```
